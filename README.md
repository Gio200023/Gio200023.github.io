# gio200023.github.io

Personal site, running on [Astro](https://astro.build) + [Spectre](https://github.com/louisescher/spectre) (MIT).

## Where things live

- Bio: `src/content/other/about.mdx`
- Work history: `src/content/work.json`
- Projects: `src/content/projects/*.mdx`
- Sidebar facts / socials: `src/content/info.json`, `src/content/socials.json`
- Site name, colour, OG tags: `astro.config.ts`
