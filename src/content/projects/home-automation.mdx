Running since 2020, still growing: a home server stack built on **Proxmox VE**, with **Home Assistant** as the automation brain.

## What it does

- Home Assistant on Proxmox VE, controlling household systems remotely.
- Reverse proxy set up for secure external access.
- Smart devices integrated for lights, gates, sensors and surveillance.
- Custom automation scripts, including person recognition for camera-triggered routines.

## Why it matters

It's the testbed where a lot of the networking, virtualisation and "will this survive a power cut" instincts I use professionally actually got built — one added service, one broken automation, one fix at a time.
